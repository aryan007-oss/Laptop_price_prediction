# Laptop Price Predictor — End-to-End ML Project

Predicts laptop price from specs (Brand, Processor Speed, RAM, Storage, Screen Size, Weight)
using `Laptop_price.csv`.

## Project structure

```
laptop_price_project/
├── Laptop_price.csv     # dataset
├── train_model.py       # EDA + preprocessing + model training + saves model.pkl
├── app.py                # Streamlit app that loads model.pkl and serves predictions
├── model.pkl              # trained pipeline (generated by train_model.py)
├── meta.pkl               # input ranges / brand list for the app's form (generated)
├── requirements.txt
└── README.md
```

## 1. Problem type

This is a **regression** problem — the target (`Price`) is a continuous number, not a category.
That rules out classifiers like `LogisticRegression`; the pipeline uses `LinearRegression`,
`Ridge`, and `RandomForestRegressor`.

## 2. Key EDA findings

- 1000 rows, no missing values.
- `Brand` is the only categorical column (Asus, Acer, Lenovo, HP, Dell).
- `Storage_Capacity` correlates with `Price` at **~0.998** — almost a straight line.
  Other features (Processor_Speed, RAM, Screen_Size, Weight) barely correlate with price.
- Because the relationship is so linear, simple linear models perform as well as (or
  better than) more complex ones like Random Forest.

## 3. Pipeline design

`train_model.py` builds a single `sklearn.pipeline.Pipeline` combining:

1. **Preprocessing** (`ColumnTransformer`):
   - One-hot encode `Brand` (`drop='first'` to avoid redundant columns).
   - Standard-scale the 5 numeric columns.
2. **Model**: trained and compared three regressors —
   `LinearRegression`, `Ridge`, `RandomForestRegressor` — using an 80/20 train/test
   split plus 5-fold cross-validation, then keeps the best performer by test R².

Wrapping preprocessing + model in one `Pipeline` means the same transformations are
applied consistently to training data, test data, and any new input the deployed app
receives — no risk of data leakage or mismatched preprocessing.

## 4. Results

| Model | Test R² | Test MAE |
|---|---|---|
| **Ridge (best)** | 0.9996 | ₹146.48 |
| LinearRegression | 0.9996 | ₹146.22 |
| RandomForest | 0.9995 | ₹168.59 |

Ridge and Linear Regression are effectively tied — expected, given how linear the
underlying relationship is. Ridge was selected automatically since it edged out
slightly on test R².

## 5. How to run it yourself

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Train the model (creates model.pkl + meta.pkl)
python train_model.py

# 3. Launch the deployment app
streamlit run app.py
```

This opens a local web page where you can enter laptop specs and get an instant
price prediction.

## 6. Deploying it publicly (optional next step)

Once it runs locally, you can put it online for free with **Streamlit Community Cloud**:

1. Push this whole folder to a GitHub repo (include `Laptop_price.csv`, `model.pkl`,
   `meta.pkl`, `app.py`, `requirements.txt`).
2. Go to [share.streamlit.io](https://share.streamlit.io), sign in with GitHub.
3. Click "New app", pick your repo, set the main file to `app.py`, and deploy.
4. Streamlit Cloud installs `requirements.txt` automatically and gives you a public URL.

Alternative options: **Render** or **Railway** (both support Streamlit apps directly),
or wrap `model.pkl` in a small **Flask/FastAPI** app and deploy as a Docker container
if you need a plain REST API instead of a UI.

## 7. Retraining on new data

If you get updated data, just replace `Laptop_price.csv` and re-run `python train_model.py` —
it regenerates `model.pkl` and `meta.pkl` automatically; `app.py` doesn't need any changes.
